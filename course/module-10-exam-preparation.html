1. You can choose Alibaba Cloud ECS instances in multiple different Regions based on the geographic distribution of your users to improve access speed and disaster tolerance. Which of the following descriptions is INCORRECT regarding ECS Regions and Availability Zones?
  • A You cannot change an ECS instance's Region after the instance has been purchased.
  • B If you deploy ECS alongside other Alibaba Cloud services such as ApsaraDB RDS, deploying them in the same Region is recommended so they can communicate over the internal network.
  • C ECS instances in different Availability Zones within the same Region and VPC under the same account are NOT interconnected via the internal network (intranet).
  • D Each Alibaba Cloud Region can contain multiple physically isolated Availability Zones.
Section 1: Cloud Architecture & Computing (ECS)
Correct Answer: C ECS instances across different Zones in the same Region and VPC ARE interconnected via the internal network.
✖ Option A is Incorrect
Regions represent physically separate global data center clusters; an ECS instance's Region is immutable after creation, requiring image migration to move across Regions.
✖ Option B is Incorrect
Same-Region deployment within the same VPC enables high-speed, zero-cost private intranet communication between ECS, RDS, SLB, and OSS.
✔ Option C is Correct
This statement is incorrect (and therefore the right answer). ECS instances in different Availability Zones within the same Region and VPC communicate seamlessly over Alibaba Cloud's internal network by default.
✖ Option D is Incorrect
Every Region consists of multiple Availability Zones with independent power grids and cooling systems connected by low-latency fiber rings.

Which deployment strategy meets this requirement?

4. Cloud disks provide triple-redundant block storage to prevent hardware-induced data loss. However, if data on a cloud disk is corrupted due to an application bug or maliciously tampered with by hackers exploiting a web vulnerability, how should an architect ensure point-in-time data recovery?
  • A Rely solely on the underlying 3-copy distributed block storage architecture without creating snapshots.

  • C Attach the corrupted system disk to 10 different ECS instances simultaneously to repair the file system.

Section 1: Cloud Architecture & Computing (ECS)
Correct Answer: B ECS Cloud Disk Snapshots enable point-in-time data restoration after application errors or malicious tampering.
✖ Option A is Incorrect

Snapshots capture point-in-time block states stored in OSS, allowing rapid rollback or disk restoration when application errors or malicious tampering occur.
✖ Option C is Incorrect
Standard cloud disks cannot be mounted in read-write mode across 10 instances simultaneously to fix logical corruption.
✖ Option D is Incorrect
Billing methods govern commercial payment terms and have zero impact on data backup or point-in-time recovery.

10. An enterprise cloud architect provisions a custom VPC with CIDR block 192.168.0.0/16 and creates a vSwitch with CIDR block 192.168.1.0/24 in Zone A. How many usable private IPv4 addresses are available for ECS instances in this vSwitch, and what is the zone scope of a vSwitch?

  • B 254 usable IP addresses, and a single vSwitch can span up to three Availability Zones simultaneously.
  • C 256 usable IP addresses with zero reserved addresses, scoped across multiple Regions.

Section 2: Virtual Private Cloud (VPC) & Networking
Correct Answer: A A /24 vSwitch provides 251 usable IPs (5 reserved) and is strictly bound to a single Availability Zone.
✔ Option A is Correct
A /24 block has 256 addresses; Alibaba Cloud reserves 4 addresses (.0 network, .253, .254 vRouter gateway, .255 broadcast) plus 1 system service IP, leaving 251 usable IPs. Each vSwitch belongs to exactly one Zone.

Alibaba Cloud reserves more than 2 addresses per vSwitch, and a vSwitch cannot span across multiple Availability Zones.

Network and gateway addresses are always reserved in IPv4 subnetting, and neither a VPC nor a vSwitch can span Regions.
✖ Option D is Incorrect
NAT Gateways consume only individual elastic/private IPs, not half of a subnet's address space.

46. When using Alibaba Cloud CDN, a user's request first reaches a CDN edge node before any back-to-origin request reaches the origin server. How can an administrator obtain the visitor's real client IP address on the origin server side? (Select 2 correct answers)
  • A The visitor's real IP can only be obtained by rewriting the backend application's core business code.
  • B The visitor's real IP is saved in the 'X-Forwarded-For' HTTP header and can be directly extracted in custom log formats of Apache and NGINX.
  • C On Windows Server running IIS, after installing the 'F5XForwardedFor' extension module, the visitor's real IP can be recorded in IIS access logs.
  • D You can click a single button in the CDN console to rewrite the origin OS TCP socket source IP without using `X-Forwarded-For` or proxy modules.
Section 7: Content Delivery Network (CDN)
Correct Answer: B, C Obtain the visitor's real IP at the origin via the HTTP X-Forwarded-For header in Apache/NGINX or IIS modules.
✖ Option A is Incorrect
Web servers like NGINX, Apache, and IIS can log the client IP directly from HTTP headers without modifying application business code.
✔ Option B is Correct
CDN appends the client's real IP to the standard `X-Forwarded-For` HTTP request header, which Apache and NGINX can log natively.
✔ Option C is Correct
Installing the `F5XForwardedFor` ISAPI filter/module on IIS extracts the `X-Forwarded-For` header into the IIS access log.
✖ Option D is Incorrect
At Layer-7 HTTP proxy back-to-origin, the TCP socket source IP is the CDN L2 node's IP; the origin must read `X-Forwarded-For` (or Proxy Protocol) to see the client IP.
